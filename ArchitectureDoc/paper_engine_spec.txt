You are an expert Go backend and trading-systems developer.

I want you to build a robust, production-style **Paper Trading + Risk Engine in Go** that:

- Consumes **strategy signals** from Kafka topic `"signals.vwap"`.
- Consumes **1-minute stock candles** from Kafka topic `"candles.1m"`.
- Simulates **intraday trades (LONG only for v1)** based on those signals.
- Enforces **simple risk rules**: per-trade SL/target, max daily loss, max trades, max open positions.
- Maintains **positions & daily PnL** in memory.
- Emits **trades** and **PnL snapshots** to Kafka for monitoring:
  - `"trades.paper"`
  - `"pnl.paper"`
- Uses a JSON config file for all parameters (Kafka, risk, trading window, timezone).
- Is structured in clean internal packages: `config`, `logging`, `kafka`, `engine`.
- Includes a short comment ABOVE every exported function/method explaining:
  - What it does
  - Inputs/outputs
  - How it fits into the flow

IMPORTANT:
- This service MUST NOT talk to any real broker.
- It MUST NOT place live orders.
- It MUST NOT do any strategy logic (no signal generation). Signals come from `"signals.vwap"`.

It is strictly:

**Kafka candles + signals → Paper Engine (positions + PnL + risk) → Kafka trades.pnl (paper)**

// SignalSide describes the direction of a signal.
type SignalSide string

const (
    SideBuy  SignalSide = "BUY"
    SideSell SignalSide = "SELL" // keep for future; v1 is long-only (BUY)
)

// StrategySignal represents an incoming trading signal from a strategy service.

    Strategy string      `json:"strategy"`

Assume:
- Signals are generated at/just after candle close.
- Signal.Time matches or is very close to the corresponding candle.Time.

7.2 Signal handling

// OnSignal processes a new StrategySignal and decides whether to open a new paper position.
// It applies trading window, daily risk limits, max open positions, and per-day trade count.
// It does NOT execute the trade immediately; instead it assumes entry at the most recent candle close.
func (e *Engine) OnSignal(sig StrategySignal, latestCandle *Candle) (*TradeEvent, error) {
    // 1. Normalize symbol to upper-case.
    // 2. Convert sig.Time to engine timezone.
    // 3. If state.Daily.TradingHalted == true -> ignore, return nil.
    // 4. If not IsWithinEntryWindow(sig.Time) -> ignore, return nil.
    // 5. If open positions >= Risk.MaxOpenPositions -> ignore, return nil.
    // 6. If tradesToday >= Risk.MaxTradesPerDay -> ignore, return nil.
    // 7. If there is already an open position for this symbol -> ignore (v1: one trade per symbol).
    // 8. Determine entry price:
    //      - If latestCandle != nil for this symbol:
    //          use latestCandle.Close as entry price.
    //        else:
    //          log warning and ignore signal (no price context).
    // 9. Compute quantity:
    //      qty = floor(Risk.CapitalPerTrade / entryPrice)
    //      if qty <= 0 -> ignore (price too high vs capital).
    // 10. Create new Position:
    //      - Symbol, SideLong, Quantity, AvgEntry=entryPrice, EntryTime=sig.Time, Strategy=sig.Strategy
    // 11. Add to state.Positions and increment Daily.TradesToday.
    // 12. Build TradeEvent of type TradeEntry with Reason = "ENTRY_FROM_SIGNAL".
    // 13. Return TradeEvent pointer.
}

Note: You can maintain a map of latest candles by symbol in the Engine, updated in OnCandle, and pass it into OnSignal.

7.3 Candle handling (SL/Target/EOD/MTM)

// OnCandle processes a new Candle, updates unrealized PnL for open positions,
// checks stop-loss and target exits, and optionally EOD flattening.
// It returns zero or more TradeEvent exits generated by this candle.
func (e *Engine) OnCandle(c Candle) ([]TradeEvent, error) {
    // 1. Normalize symbol and time to tz.
    // 2. CheckAndResetDayIfNeeded(c.Time).
    // 3. If there is an open position for c.Symbol:
    //      - For LONG:
    //           slPrice     = position.AvgEntry * (1 - Risk.PerTradeSLPct/100)
    //           targetPrice = position.AvgEntry * (1 + Risk.PerTradeTargetPct/100)
    //        Use candle O/H/L/C to decide if SL or target is hit in this candle.
    //
    //        Pseudo:
    //           hitSL := c.Low <= slPrice
    //           hitTP := c.High >= targetPrice
    //
    //        Rule v1 (conservative):
    //          - If hitSL:
    //               exitPrice = slPrice
    //               reason = "EXIT_SL_HIT"
    //          - Else if hitTP:
    //               exitPrice = targetPrice
    //               reason = "EXIT_TARGET_HIT"
    //          - Else if IsAfterEODFlatTime(c.Time):
    //               exitPrice = c.Close
    //               reason = "EXIT_EOD"
    //          - Else: no exit.
    //
    //        If we exit:
    //           realized = (exitPrice - AvgEntry) * Quantity
    //           update Daily.RealizedPnl += realized
    //           update drawdown: compare Daily.RealizedPnl vs previous peak.
    //           remove position from Positions map.
    //           build TradeEvent of type TradeExit with RealizedPnl set.
    //
    // 4. After processing exits, recompute UnrealizedPnl for all remaining positions:
    //      - For each open position p:
    //           if we have a recent candle for p.Symbol (including c if same symbol):
    //              mtmPrice = lastClose
    //              unreal += (mtmPrice - p.AvgEntry) * p.Quantity
    //      - state.Daily.UnrealizedPnl = unreal
    //
    // 5. Check daily loss limit:
    //      if Daily.RealizedPnl <= -Risk.MaxDailyLoss:
    //          set Daily.TradingHalted = true
    //          // (For v1, DO NOT auto-close open positions here; they still follow SL/TP/EOD.)
    //
    // 6. Return slice of exit TradeEvents.
}

9. ERROR HANDLING
=====================================================================

- JSON unmarshal error (signals or candles):
  - Log warning with enough context (topic, raw value truncated).
  - Skip and continue.

- Time parse error:
  - Log and skip that message.

- Kafka poll error:
  - Log; if fatal, exit main (return error) and let supervisor restart.

- Kafka produce error:
  - Log error; skip that event. Do NOT panic.

- Panics:
  - Optional: recover in main, log stack trace, then exit.
