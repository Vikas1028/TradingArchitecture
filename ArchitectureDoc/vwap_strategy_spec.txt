You are an expert Go backend and trading-systems developer.

I want you to build a robust, production-style **VWAP Strategy Service in Go** that:

- Consumes **index candles** from Kafka topic `"indices.1m"` (e.g., NIFTY, BANKNIFTY).
- Consumes **stock candles** from Kafka topic `"candles.1m"`.
- Maintains a **market bias** (LONG_ONLY / SHORT_ONLY / NONE) based on NIFTY/BANKNIFTY candles vs their VWAP.
- Applies a **VWAP pullback LONG strategy** on stock candles, using the index bias as a filter.
- Emits **trade signals (BUY only for v1)** to Kafka topic `"signals.vwap"`.
- Uses a JSON config file for Kafka settings, logging, strategy parameters, and timezone.
- Is split into clean internal packages: `config`, `logging`, `kafka`, `strategy`.
- Adds a short comment ABOVE every exported function/method explaining:
  - What it does
  - Its inputs/outputs
  - How it fits into the pipeline

This service MUST NOT:

- Place any orders.
- Talk to any broker.
- Track PnL or positions.
- Serve HTTP.
- Decide quantities or risk.

It is strictly:

**Kafka "indices.1m" + "candles.1m" → VWAP pullback brain → Kafka "signals.vwap"**

1. INPUT CANDLE SCHEMA
=====================================================================

Both topics `"indices.1m"` and `"candles.1m"` use the same JSON schema:

{
  "symbol": "RELIANCE",
  "time": "2025-12-07T09:21:00+05:30",
  "open": 2708.5,
  "high": 2711.0,
  "low": 2707.8,
  "close": 2710.25,
  "volume": 50000,
  "vwap": 2709.75
}

// Candle represents a 1-minute OHLCV bar with VWAP produced by the marketdata service.
type Candle struct {
    Symbol string    `json:"symbol"`
    Time   time.Time `json:"time"`
    Open   float64   `json:"open"`
    High   float64   `json:"high"`
    Low    float64   `json:"low"`
    Close  float64   `json:"close"`
    Volume int64     `json:"volume"`
    VWAP   float64   `json:"vwap"`
}

Behavior:
- Parse `"time"` with `time.Parse(time.RFC3339Nano, rawTime)`.
- Normalize `Symbol` to upper-case for internal processing: `strings.ToUpper`.

2. OUTPUT SIGNAL SCHEMA (Kafka "signals.vwap")
=====================================================================

Output topic (default): `"signals.vwap"` (configurable).

Each message is a **strategy signal**, no quantities, no order IDs:

{
  "strategy": "VWAP_PULLBACK_V1",
  "symbol": "RELIANCE",
  "side": "BUY",
  "time": "2025-12-07T10:05:00+05:30",
  "reason": "INDEX_BIAS_LONG_PULLBACK_CONFIRMED"
}

In Go (internal/strategy/types.go):

// SignalSide describes the direction of a signal.

// OnIndexCandle ingests a new index Candle, updates rolling history, and recalculates market bias.
// BiasLong if majority of recent closes are above (VWAP + threshold); BiasShort if below; otherwise BiasNone.
func (b *BiasEngine) OnIndexCandle(c Candle) MarketBias {
    // 1. Normalize symbol to upper-case.
    // 2. Append candle to indexState[symbol].Candles, truncate length to cfg.IndexBiasLookback.
    // 3. For recent candles, compute (Close - VWAP) / VWAP * 100.
    // 4. Count how many > +cfg.IndexBiasVWAPThresh -> posCount
    //    and how many < -cfg.IndexBiasVWAPThresh -> negCount.
    // 5. If posCount > negCount and posCount is significant -> b.current = BiasLong.
    //    Else if negCount > posCount and negCount significant -> b.current = BiasShort.
    //    Else b.current = BiasNone.
    // 6. Return b.current.
}

// CurrentBias returns the last computed MarketBias.
func (b *BiasEngine) CurrentBias() MarketBias {
    return b.current
}

// OnStockCandle processes a new stock Candle and, if all VWAP pullback and index bias conditions
// are satisfied, returns a BUY StrategySignal. Otherwise, it returns nil.
func (s *VwapPullbackStrategy) OnStockCandle(c Candle, bias MarketBias) *StrategySignal {
    // 1. Normalize symbol: symbol := strings.ToUpper(c.Symbol)
    // 2. Convert time to tz if needed: candleTime := c.Time.In(s.tz)
    // 3. Check if candleTime within [EntryStart, EntryEnd] configured window:
    //    - Parse EntryStart and EntryEnd (HH:MM) into time-of-day and compare.
    //    - If outside -> return nil.
    //
    // 4. Get or create SymbolTrendState for this symbol.
    //    - Append candle to state.Candles.
    //    - Truncate history length to some max (TrendLookback + PullbackWindow + buffer).
    //
    // 5. If cfg.EnableIndexBias:
    //    - If bias != BiasLong -> return nil (we only trade LONG when bias is LONG).
    //
    // 6. Ensure we have at least TrendLookback candles in state.Candles; if not, return nil.
    //
    // 7. TREND CHECK (last cfg.TrendLookback candles):
    //    - Count how many of these have Close > VWAP.
    //    - If (count / TrendLookback) < 0.7 (for example), return nil (no strong uptrend).
    //
    // 8. PULLBACK CHECK (last cfg.PullbackWindow candles):
    //    - Ensure we have at least PullbackWindow candles.
    //    - For candles in the last PullbackWindow, compute:
    //          distPct = |Low - VWAP| / VWAP * 100
    //      If none of them have distPct <= cfg.MaxPullbackPct, return nil
    //      (price did not come close enough to VWAP recently).
    //
    // 9. CONFIRMATION CHECK (current candle, c):
    //    - Must be a green candle: c.Close > c.Open
    //    - c.Close > c.VWAP
    //    - Compare with previous candle (second last in state.Candles before appending, or index carefully):
    //        previousHigh := previousCandle.High
    //        If c.Close <= previousHigh -> return nil
    //    - Candle body strength:
    //        range := c.High - c.Low
    //        if range <= 0 -> return nil
    //        body := c.Close - c.Open
    //        bodyPct := (body / range) * 100
    //        if bodyPct < cfg.MinBodyPct -> return nil
    //
    // 10. If all conditions satisfied, construct a BUY StrategySignal:
    //      return &StrategySignal{
    //          Strategy: "VWAP_PULLBACK_V1",
    //          Symbol:   symbol,
    //          Side:     SideBuy,
    //          Time:     candleTime,
    //          Reason:   "INDEX_BIAS_LONG_PULLBACK_CONFIRMED",
    //      }
    //
    // 11. Otherwise, return nil.
}

Notes:
- v1 is **LONG-only**; side = BUY when conditions meet.
- No position tracking or duplicate suppression here; that will be done in a later Risk/Order service.

9. ERROR HANDLING RULES
=====================================================================

- JSON unmarshal error for Candle:
  - Log warning with topic + symbol (if present).
  - Skip and continue.

- Time parse error:
  - Log, skip candle.

- Kafka poll error:
  - Log; if fatal error type → return from main and let supervisor restart.

- Kafka produce error:
  - Log; skip that signal and continue.

- Panic:
  - Optional: recover in main, log stack trace, and exit.
