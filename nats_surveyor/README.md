# NATS Surveyor

This directory is an infrastructure wrapper around the external `nats-surveyor` binary.

Tracked source assets in this repo are:

- `config/nats-surveyor.yaml`
- `scripts/start_mac.sh`
- `scripts/stop_mac.sh`
- `scripts/nats_surveyor.plist`
- `scripts/nats_surveyor.properties`
- `bin/README.md`

This is not an application service implemented in this repository. The surveyor binary itself is external infrastructure.
