# NATS Service

This directory is an infrastructure wrapper around an external `nats-server` installation.

Tracked source assets in this repo are:

- `config/nats-server.conf`
- `scripts/start_mac.sh`
- `scripts/stop_mac.sh`
- `scripts/nats.plist`
- `scripts/nats.properties`

This is not an application service implemented in this repository. The NATS server binary itself is external infrastructure.
